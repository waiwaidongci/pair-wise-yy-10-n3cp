# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

业务文件划分：
- `grading.js`：判定——定级资格、等级判定、审签发证、证书失效与按新值重判。
- `store.js`：存放——localStorage 读写、旧版数据迁移、证书编号发放。
- `app.js`：页面——看板、证书队列、作品履历的渲染与交互。

已实现闭环：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 进度满 100% 且无缺陷的作品可申请一条未结束定级；等级、检验人、签发人齐备且检验≠签发才发证，否则整单拒绝、不留半截。
- 证书编号唯一，重复或并发申请沿用首次结果。
- 改动胎体、纹样、线条或缺陷会使已发证书失效并按新值重判，旧证书只读保留。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出；刷新后看板、证书队列、作品履历一致。
