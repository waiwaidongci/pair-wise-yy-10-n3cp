# zfl-42 漆线雕工坊 · 定级审签与证书发放台

独立静态前端应用，直接打开 `index.html` 即可使用（数据存浏览器 localStorage）。

## 文件分工

| 文件 | 职责 |
| --- | --- |
| `store.js` | **存放层**：localStorage 读写（`zfl42Studio.v2`）、整单原子提交、重复/并发请求幂等台账、证书编号唯一发号；旧版 `zfl42Works` 数据首次打开自动迁移 |
| `grading.js` | **判定层**：定级资格、申请/审签/拒绝、证书发放、作品核心值变更触发旧证失效与按新值重判 |
| `app.js` | **页面层**：工序看板、定级审签证书队列、证书台账、作品详情与履历；只渲染 `Store.load()` 的单一事实源 |
| `index.html` | 布局与样式 |
| `test-rules.js` | Node 规则链验证（`node test-rules.js`，19 项断言） |

## 业务规则

- **申请资格**：仅贴线进度 100% 且无缺陷记录的作品可申请定级；同一作品同时只允许一条未结束（定级中）定级，已有有效证书不得重复申请。
- **审签**：等级、检验人、签发人齐备，且检验人与签发人不得为同一人。任一条件不满足 → **整单拒绝**：所有校验在草稿上跑完才落盘，不留半截数据，整改后可重新申请。
- **证书**：签发即发证书，编号 `QXD-年份-序号`，台账内全局唯一、年内自增；重复或并发的申请/签发沿用首次结果（幂等键存于 `requests`）。
- **失效与重判**：改动作品的胎体材质、纹样主题、线条粗细或缺陷后，有效证书立即转为「已失效」只读存档（保留出证时取值快照），进行中的定级取消并按新值自动开一条「重判」单；新值不再满足资格（有缺陷/进度不满）则不开单，整改完成后手动重新申请。
- **一致性**：看板徽章、证书队列、证书台账、作品履历全部读同一份状态，任何写操作成功后整体重渲染，刷新页面后视图一致。

## 原有功能

新增作品（胎体、纹样、线条、进度、阴干/交付日期、金粉、缺陷、备注）、四列工序看板（贴线中/待阴干/上金粉/待交付）、今日待阴干/缺陷作品/最近交付列表、筛选排序、JSON 导出。
